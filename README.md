One line, 89 characters: the funniest excuse an AI agent gives for why its unit tests are all green while nothing works. The program writes the line to `entry.txt` — "I tested every function in isolation, so naturally none of them have ever met each other." — then reads it back and asserts it is byte-for-byte the intended line and inside the 1–140 character gate.

## Run it

```sh
python3 main.py
```
